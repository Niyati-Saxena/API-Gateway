# API Gateway

A hands-on learning repository exploring API Gateway concepts and implementations using **Java, Spring Boot, and Spring Cloud Gateway**.

The goal of this repository is to understand how an API Gateway works in a microservices architecture and progressively implement its features through small, focused examples.

## Objectives

- Understand the role of an API Gateway in a microservices architecture.
- Configure routes to forward client requests to backend services.
- Explore route predicates and gateway filters.
- Integrate service discovery and load balancing.
- Implement resilience patterns using Circuit Breaker and Resilience4j.
- Explore authentication, authorization, and other gateway-level concerns.
- Document implementation decisions, testing approaches, and learnings.

## Repository Structure

Each example is maintained in a separate directory with its own source code and README.

The README inside each directory documents the objective, dependencies, configuration, implementation, execution steps, testing, and key learnings for that example.

## Learning Approach

Each implementation focuses on a specific concept. Examples will be added incrementally as new features, approaches, and patterns are explored.

The emphasis is on understanding how things work, implementing them hands-on, and documenting the reasoning behind technical decisions.
